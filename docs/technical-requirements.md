# LitWeave 技術要件

## 構成

- バックエンド: Python 3.12、FastAPI、SQLAlchemy 2、Alembic、Pydantic
- ローカル索引: SQLite（`%LOCALAPPDATA%\LitWeave\litweave.db`）
- フロントエンド: React、TypeScript、Vite
- グラフ: Cytoscape.js
- テスト: pytest、Vitest、Testing Library

アプリバージョンの正本は`backend/app/version.py`の`VERSION`とし、FastAPIのOpenAPI情報と`/api/system`を通じて画面へ渡す。Pythonパッケージのバージョンは配布メタデータであり、実行時の正本にはしない。

## データ境界

Box Drive配下の`paper.pdf`、`metadata.json`、`note.md`、`config/*.json`、`citations/*.json`が正本である。SQLiteは一覧・検索用索引に限定し、Box Drive内へ置かない。APIへ任意のPDFパスを渡さず、UUIDから索引の表示IDを取得し、`P000001`形式を検証して管理ルート配下へ解決する。

JSON、Markdown、PDFは同一ディレクトリの一時ファイルへ書き、flushとfsync後に`os.replace`で確定する。PDFはコピー後のSHA-256を元ファイルと比較する。登録失敗時は未完成の論文ディレクトリを削除する。

## ローカル動作とプライバシー

開発サーバーは`127.0.0.1`だけで待ち受ける。外部API、Box API、テレメトリーを使用しない。フリーテキスト検索語、PDF本文、メモ本文、元PDFのパスをログへ記録しない。ログには操作結果、例外型、OSエラーコードだけを記録し、`%LOCALAPPDATA%\LitWeave\logs`で30世代を保持する。MarkdownはHTMLへ変換せずプレーンテキストとして編集するため、埋め込みスクリプトは実行されない。

開発UIはPDF登録をViteのプロキシへ中継せず、`127.0.0.1:8000`へ直接送信する。登録前にブラウザ側でPDFシグネチャを実際に読み、オンライン専用ファイルなど読み出せない入力を送信前に拒否する。

Box Drive保存先が存在しない場合は正本への更新を拒否し、別フォルダーへ保存しない。画面はローカル索引を読み取り専用で参照できる。Box Driveフォルダーへの書き込み完了とBoxクラウド同期完了は明確に区別する。

## 索引再構築

再構築はSQLiteを作り直し、キーワード、通常論文、ごみ箱内論文、論文の`metadata.json`内のタスク、引用関係の順で正本を読み込む。各論文・引用を個別トランザクションで処理し、異常ファイルのIDと理由を返して残りを継続する。不完全データは通常一覧に現れない。

## 重複判定とPDF差し替え

PDFのSHA-256完全一致は登録を停止する。DOIは接頭辞除去後に大文字小文字を無視して比較し、タイトルはUnicode NFKC正規化、大文字小文字の無視、連続空白の統合を行って比較する。DOI一致、正規化タイトルと発行年の一致、または正規化タイトル一致かつ片方の発行年が未入力の場合は候補を返し、ユーザーが既存論文を開く、PDFを差し替える、別論文として登録する、登録を中止する操作を選択する。

PDF差し替えは新旧PDFを管理対象ディレクトリ内へ一時保存してハッシュを検証してから、現在の`paper.pdf`を`versions/paper.pdf`へ退避する。旧版は1世代だけ保持する。ファイル置換またはメタデータ更新に失敗した場合は現在のPDFと既存の旧版を復元する。差し替え後はPDFハッシュ、サイズ、`pdf_replaced_at`、更新日時を正本とSQLiteの両方へ保存する。

## UI

起動時はホームを表示し、専用ダッシュボードを設けない。登録と詳細編集は専用画面で行う。CSS Gridと可変幅を使用し、Windows表示倍率125～200%で横幅が不足した場合は1列レイアウトまたは表の横スクロールへ移行する。

## マイグレーション

`backend/migrations`をAlembicの正本とする。初回起動時の`create_all`も行い、空のローカル環境を追加操作なしで起動可能にする。先行して作成済みのローカル索引にタスクの`description`列または論文の`pdf_replaced_at`列がなければ起動時に追加する互換処理を行う。スキーマ変更はAlembicリビジョンで管理する。

## 後続実装

バックアップ復元、自動バックアップ、完全バックアップ、Markdownプレビュー／折りたたみ、性能ベンチマークは後続版で追加する。正本形式の互換性を維持し、既存データを破壊する変更はマイグレーションを伴わせる。
