# LitWeave 要件定義書

## 1. 文書情報

- アプリ名: LitWeave（リットウィーブ）
- コンセプト: 論文を編み、知識をつなぐ
- 対象リリース: 初版
- 文書状態: 初版要件確定
- 最終更新日: 2026-07-24

## 2. 目的

LitWeaveは、ユーザーが入手した論文PDFを一元管理し、読書状態、書誌情報、定型メモ、キーワードおよび引用関係を整理・可視化する個人向けローカルアプリである。

論文検索やPDF入手そのものはLitWeaveの外で行い、LitWeaveは入手後の論文整理と知識の参照に特化する。

## 3. 想定利用環境

- Windows 11
- 利用者は1人
- Box Driveを利用
- 基本的に1台のPCで利用
- UIは日本語
- 日本語・英語の論文情報とメモを保存可能
- インターネット接続がなくても、Box Drive上のファイルが端末に保持されていれば利用可能

## 4. 基本方針

- 新規論文登録にはPDFを必須とする。
- PDF登録時の初期状態は「未読」とする。
- PDF、メモおよび復元用メタデータはBox Drive配下の指定フォルダへ保存する。
- SQLiteはローカルに置き、検索・一覧・グラフ表示用の再構築可能なインデックスとして使用する。
- Box Drive上のファイルを復元可能な正本とする。
- Box APIは使用せず、Box Drive配下の通常のファイルとして読み書きする。
- 論文のつながりは、キーワードと引用関係から表現する。

## 5. 対象範囲

### 5.1 初版に含める機能

- 初回セットアップ
- PDF必須の論文登録
- 書誌情報の登録・編集
- 読書状態の管理
- 論文一覧、検索、絞り込み、並べ替え
- Windowsの既定アプリによるPDF表示
- キーワードの作成・付与・編集・統合
- 定型Markdownメモ
- 登録済み論文間の引用関係
- キーワードグラフ
- 引用グラフ
- ごみ箱、復元、完全削除
- 軽量バックアップ
- SQLiteインデックスの再構築
- CSV、JSON、Markdownによるエクスポート

### 5.2 初版に含めない機能

- アプリ内での論文検索
- 論文の自動ダウンロード
- PDFなしの論文登録
- AI要約、AI検索、キーワード自動生成
- PDF本文の全文検索
- PDFへのハイライトや注釈
- アプリ内PDFビューア
- Wordへの引用挿入
- 参考文献形式の自動生成
- DOIからの書誌情報自動取得
- Zoteroとの連携
- Box APIとの連携
- クラウド共同編集
- 複数ユーザー
- スマートフォン版
- macOS版
- 外部エディタによるメモ変更のリアルタイム監視
- 外部編集との競合検出・自動統合

## 6. 基本ワークフロー

1. ユーザーが外部サイト等で論文を検索し、PDFを入手する。
2. LitWeaveでPDFを選択またはドロップする。
3. LitWeaveがPDFの形式と重複を確認する。
4. ユーザーがタイトルなどの論文情報を入力する。
5. LitWeaveがPDFをBox Drive上のライブラリへコピーする。
6. 論文を「未読」として登録する。
7. ユーザーがキーワードを付与する。
8. 読書状況に応じて「読書中」「既読」「再確認」へ変更する。
9. 定型フォーマットでメモを作成する。
10. 必要に応じて、登録済み論文との引用関係を設定する。
11. 一覧、検索、絞り込み、キーワードグラフ、引用グラフから論文を参照する。

## 7. 保存構成

### 7.1 Box Drive

初期値として、次の保存先を想定する。

```text
C:\Users\<ユーザー名>\Box\LitWeave Library\
```

保存先は初回セットアップ時にユーザーが指定する。

```text
LitWeave Library\
├─ items\
│  └─ P000001\
│     ├─ paper.pdf
│     ├─ note.md
│     ├─ metadata.json
│     └─ versions\
├─ citations\
│  └─ C000001.json
├─ config\
│  ├─ keywords.json
│  └─ settings.json
├─ trash\
└─ backups\
```

### 7.2 ローカルデータ

```text
%LOCALAPPDATA%\LitWeave\
├─ litweave.db
└─ logs\
```

- `litweave.db`は検索・表示用インデックスであり、正本ではない。
- Box Drive上のファイルから再構築できること。
- SQLiteデータベースをBox Drive内へ置かないこと。

## 8. 論文データ

### 8.1 必須項目

| 項目 | 内容 |
|---|---|
| 内部ID | UUID。アプリが自動生成する |
| 表示ID | `P000001`形式。アプリが自動採番する |
| タイトル | 空欄不可 |
| PDF | 登録時必須 |
| 状態 | 初期値は「未読」 |
| 登録日時 | アプリが自動記録する |

### 8.2 任意項目

| 項目 | 内容 |
|---|---|
| 著者 | 複数、順序あり |
| 発行年 | 西暦4桁 |
| ジャーナル | 文字列 |
| 巻 | 文字列 |
| 号 | 文字列 |
| ページ | ページ範囲または記事番号 |
| DOI | 正規化して保存 |
| URL | 論文ページ等 |
| 言語 | 日本語、英語、その他 |
| 要旨 | 既存データとの互換性のため保持する。画面では入力・編集しない |
| 評価 | 未評価または1～5 |
| 読了日 | 日付 |
| 備考 | 既存データとの互換性のため保持する。画面では入力・編集しない |

論文種別は初版では管理しない。

### 8.3 著者

- 著者は1つの文字列にまとめず、複数・順序ありで保存する。
- 初版では表示名と著者順だけを保持する。
- 姓名の分離、所属、ORCIDは管理しない。

### 8.4 DOI

- `https://doi.org/`および`doi:`を除去して保存する。
- 前後の空白を除去する。
- 比較時は大文字・小文字を区別しない。
- DOI形式が疑わしい場合は警告するが、保存は許可する。

### 8.5 タスク

- 論文ごとに複数のタスクを登録できる。
- 各タスクはタスクID、タイトル、詳細、完了状態、作成日時、更新日時を持つ。
- タスクは論文の`metadata.json`内へ保存し、SQLite索引を再構築できる。
- タイトルは空欄不可、最大200文字とする。
- 詳細は任意入力、最大4,000文字とする。
- 完了したタスクも論文詳細から確認できる。
- ホーム右側の細幅領域に、すべての論文のタスクを表形式でまとめて表示する。

### 8.6 評価

評価は論文の絶対的品質ではなく、ユーザーにとっての参考度を示す。

| 評価 | 意味 |
|---:|---|
| 1 | 参考性が低い |
| 2 | 一部参考になる |
| 3 | 参考になる |
| 4 | 重要 |
| 5 | 非常に重要 |
| 未評価 | まだ判断していない |

## 9. 読書状態

状態は次の4種類とする。

| 状態 | 意味 |
|---|---|
| 未読 | 登録済みだが読んでいない |
| 読書中 | 現在読んでいる |
| 既読 | 一度読み終えた |
| 再確認 | 後から読み直す必要がある |

- PDF登録時は「未読」とする。
- 状態変更日時を履歴として保存する。
- 初めて「既読」へ変更したときは、当日を読了日の候補とする。
- 読了日はユーザーが変更・削除できる。

## 10. 検索・絞り込み・並べ替え

### 10.1 検索

フリーテキスト検索の対象は次の3項目だけとする。

- タイトル
- 著者
- キーワード

次の項目は検索対象にしない。

- ジャーナル
- DOI
- URL
- 要旨
- メモ本文
- PDF本文
- 備考
- タスク

検索ルールは次のとおり。

- 大文字・小文字を区別しない。
- 日本語・英語とも部分一致とする。
- 複数語は空白で区切る。
- 複数語は、タイトル・著者・キーワードを横断して、すべて一致する論文を表示する。

### 10.2 絞り込み

- 状態
- 発行年
- ジャーナル
- キーワード
- 評価

### 10.3 並べ替え

- ホームの論文一覧は更新日時の新しい順で表示する。
- 初版では画面上に並べ替え操作を設けない。

## 11. キーワード

各キーワードは次の情報を持つ。

- キーワードID
- 表示名
- 比較用の正規化名
- 色
- 作成日時
- 更新日時

入力・管理ルールは次のとおり。

- 前後の空白を除去する。
- 空欄を許可しない。
- 大文字・小文字を無視して重複判定する。
- 表示名は最初に登録した表記を維持する。
- 同じ論文に同一キーワードを重複付与できない。
- 使用中のキーワードは確認なしで削除できない。
- キーワードを別のキーワードへ統合できる。
- 初版ではキーワードの階層、別名、自動生成を扱わない。

## 12. メモ

### 12.1 保存形式

- 論文ごとに`note.md`として保存する。
- Markdown記法を使用できる。
- すべてのセクションは任意入力とし、空欄のまま保存できる。
- `Ctrl+S`または保存ボタンで保存する。
- 未保存状態を画面上に表示する。
- 未保存のまま移動・終了しようとした場合は確認する。
- 編集欄でMarkdown記法を色分け表示する。
- 箇条書きの改行時に次の項目を継続し、Tabでインデントできる。
- 編集欄内の検索、元に戻す、やり直しを利用できる。
- 選択範囲へ`Ctrl+B`で太字、`Ctrl+I`で斜体、`Ctrl+K`でリンクのMarkdown記法を追加できる。
- 編集とプレビューを切り替えられる。
- プレビューには保存前の編集中の内容を反映する。
- プレビューでは段落内の1回の改行を入力どおり表示する。
- セクションを画面上で折りたためる。

### 12.2 既定テンプレート

1. 要約
2. 研究方法・条件
3. 主な結果
4. 評価・疑問
5. 自分の研究への活用
6. 関連文献

```markdown
## 要約

## 研究方法・条件

## 主な結果

## 評価・疑問

## 自分の研究への活用

## 関連文献
```

### 12.3 テンプレート変更

- 設定画面からセクションを追加できる。
- セクション名を変更できる。
- セクションを並べ替えられる。
- セクションを削除できる。
- 既定テンプレートへ戻せる。
- テンプレート変更は新規登録する論文に適用する。
- 既存メモを自動変更しない。

### 12.4 外部編集

- `note.md`は外部エディタでも開ける。
- LitWeaveで論文詳細を開いた時点の内容を読み込む。
- 初版では外部変更をリアルタイム監視しない。
- LitWeaveと外部エディタの同時編集による競合を検出しない。
- 同時編集した場合、後から保存した内容で上書きされる可能性がある。

### 12.5 次のアクション

- 次のアクションはMarkdownメモへ記載せず、論文に紐づくタスクとして管理する。
- タスクの追加、完了・未完了の切り替え、削除は論文詳細画面で行う。
- メモとタスクは別々に保存する。

## 13. 引用関係

- LitWeaveに登録済みの論文同士を手動で接続する。
- 引用関係には方向がある。
- 引用元から引用先へ矢印を表示する。
- 同じ引用関係を重複登録できない。
- 自分自身への引用関係を登録できない。
- PDFの参考文献一覧からの自動抽出は行わない。

引用関係は次の情報を持つ。

- 引用関係ID
- 引用元論文ID
- 引用先論文ID
- 補足メモ（任意）
- 作成日時

## 14. ナレッジグラフ

### 14.1 表示モード

- キーワードグラフ
- 引用グラフ

キーワードグラフは論文ノードとキーワードノードを表示し、論文へ付与されたキーワードから自動生成する。

引用グラフは登録済み論文間の引用関係を方向付きで表示する。

### 14.2 全体グラフ

- 固定のノード上限を設けない。
- 条件に一致するノードをすべて表示する。
- ノードを勝手に間引いたり省略したりしない。
- ノード数と接続数を表示する。
- 大規模な場合は、表示に時間がかかる可能性を案内する。

### 14.3 ローカルグラフ

- 選択した論文の周辺だけを表示できる。
- 表示する接続の深さを1～3段階で指定できる。

### 14.4 共通操作

- 状態、発行年、キーワードで絞り込める。
- ノードをクリックすると右側に概要を表示する。
- 論文ノードから論文詳細へ移動できる。
- 拡大、縮小、移動ができる。
- レイアウトを初期状態へ戻せる。

## 15. 画面構成

### 15.1 ナビゲーション

```text
LitWeave
├─ ホーム
│  ├─ 論文一覧
│  ├─ 論文登録
│  ├─ 論文詳細
│  └─ タスク
├─ ナレッジグラフ
├─ キーワード管理
├─ ごみ箱
└─ 設定
```

起動時はホーム画面を表示する。独立したダッシュボード画面は設けず、ホーム上部に状態別件数を表示する。

### 15.2 初回セットアップ

- Box Drive配下のライブラリ保存先を選択する。
- 保存先の存在、書き込み権限を確認する。
- 必要なフォルダを作成する。
- 対象フォルダをBox Driveで「常にこのデバイスに保持」するよう案内する。

### 15.3 ホーム

- 初版は表形式だけを提供する。
- 左側に論文一覧、右側に細幅のタスク表を同時に表示する。
- 画面幅が不足する場合は、論文一覧の下へタスク表を移動する。
- 状態、タイトル、著者、発行年、キーワード、評価、登録日を表示する。
- タイトルと著者は1行で表示し、長い場合は折り返さず省略表示する。
- 評価は未評価を含めて5段階の星で表示する。
- 行全体を選択して論文詳細へ移動できる。
- 一覧上の状態は表示専用バッジとし、状態変更は論文詳細で行う。
- キーワードを選択して絞り込める。

### 15.4 論文登録

- モーダルではなく専用画面とする。
- PDFをドラッグ＆ドロップまたはファイル選択で登録できる。
- 重複確認後に論文情報を入力する。
- タイトルとPDFだけを必須とする。
- キーワード管理で登録済みのキーワードをタグ形式で選択し、論文登録と同時に付与できる。
- 要旨と備考の入力欄は表示しない。

### 15.5 論文詳細

次のタブを持つ。

- 基本情報
- メモ
- タスク
- 引用
- 履歴

主な操作は次のとおり。

- 基本情報では要旨と備考の入力欄を表示しない。

- 状態変更
- PDFをWindowsの既定アプリで開く
- 書誌情報編集
- タスクの追加、タイトル・詳細の編集、完了・未完了の切り替え、削除
- メモ編集
- 引用関係追加・削除
- ごみ箱へ移動

### 15.6 ホーム内タスク表

- 全論文のタスクを表形式で表示する。
- ホーム画面の右側に、論文一覧より細い領域で表示する。
- 完了チェックと、タイトル、詳細、対象論文、更新日を縦にまとめて表示する。
- 初期状態では未完了タスクだけを表示する。
- 完了済みタスクを含めて表示できる。
- 表から完了・未完了を切り替えられる。
- 対象論文の詳細画面へ移動できる。

### 15.7 キーワード管理

- 新規作成
- 名前変更
- 色変更
- 使用論文一覧
- 別キーワードへの統合
- 未使用キーワードの削除

### 15.8 ごみ箱

- 元に戻す
- 完全削除
- 削除日時の確認
- ごみ箱を空にする

### 15.8 設定

- ライブラリ保存先
- Box Drive利用状態
- メモテンプレート
- 既定言語
- バックアップ作成
- SQLiteインデックス再構築
- CSV、JSON、Markdown出力
- アプリのバージョン情報

## 16. 重複判定

### 16.1 登録を停止する条件

- PDFのSHA-256が既存PDFと完全一致する。

既存論文への移動操作を提示する。

### 16.2 警告する条件

- DOIが一致する。
- 正規化したタイトルと発行年が一致する。
- 正規化したタイトルが一致し、発行年が片方未入力である。

警告時は次の操作を選べる。

- 既存論文を開く。
- 既存論文のPDFを差し替える。
- 別論文として登録する。
- 登録を中止する。

## 17. PDF差し替え

- 現在のPDFを`versions`へ退避してから差し替える。
- 初版では旧版を1世代だけ保持する。
- 差し替え後にハッシュ、ファイルサイズ、差し替え日時を更新する。

## 18. 削除と復元

### 18.1 通常削除

- 論文フォルダを`items`から`trash`へ移動する。
- 一覧とグラフから非表示にする。
- 引用関係は保持し、復元時に再表示する。

### 18.2 完全削除

- 論文フォルダを削除する。
- 対象論文を含む引用関係を削除する。
- ローカルインデックスから削除する。
- 完全削除前に対象と削除内容を明示して確認する。

## 19. Box Drive利用時の挙動

| 状態 | LitWeaveの動作 |
|---|---|
| 保存先が利用可能・書き込み可能 | 通常動作 |
| Box Driveが停止 | 読み取り専用で起動 |
| 保存先が見つからない | 警告して新規登録・編集を停止 |
| 書き込み権限がない | 保存を中止して理由を表示 |
| Box Driveが同期中 | Box Driveフォルダへのローカル保存を許可 |

- LitWeaveは「Box Driveフォルダへ保存済み」までを表示する。
- Boxクラウドへの同期完了を保証・表示しない。
- Boxが利用できない場合に、別の場所へ勝手に保存しない。

## 20. 保存の信頼性

- PDFは一時ファイルへコピー後、元PDFとハッシュを比較してから確定する。
- JSONとMarkdownは一時ファイルへ書き込み、正常に保存できた場合に正式ファイルへ置換する。
- 登録途中で失敗した論文を通常一覧へ表示しない。
- SQLite更新だけが失敗した場合は、Box側の保存を正本として保持し、インデックス再構築対象とする。
- 各JSONにスキーマバージョンを保持する。

## 21. バックアップ・復元・エクスポート

### 21.1 軽量バックアップ

- PDFを除くメタデータ、メモ、キーワード、引用関係、設定をZIPへ保存する。
- 初期設定では7日ごとに自動作成する。
- 直近5世代を保持する。

### 21.2 完全バックアップ

- PDFを含むライブラリ全体を対象とする。
- 容量が大きいため手動実行とする。
- 保存先はBox Drive外も選択できる。

### 21.3 復元

- Box Drive上の正本からSQLiteを再構築できる。
- 異常なファイルがあっても再構築全体を停止しない。
- 問題のある論文IDと理由を一覧表示する。

### 21.4 エクスポート

- 論文一覧: CSV
- 全メタデータ: JSON
- メモ: Markdown
- キーワード一覧: CSV
- 引用関係: CSV
- ライブラリ全体: ZIP

初版ではBibTeXとRISを対象外とする。

## 22. 性能要件

初版では次を目安とする。

- 論文数: 5,000件
- キーワード数: 2,000件
- 引用関係: 20,000件
- 一覧初期表示: 2秒以内
- 通常検索: 1秒以内
- 論文詳細表示: 1秒以内
- PDF登録処理: ファイルコピー時間を除き2秒以内
- SQLite再構築: 5,000件で5分以内

グラフの固定表示上限は設けず、実装後に1,000件および5,000件相当のテストデータで性能を検証する。

## 23. セキュリティ・プライバシー

- 外部サーバーへ論文情報を送信しない。
- 利用状況やテレメトリーを送信しない。
- Box APIキーを保持しない。
- ローカルサーバーを使用する場合は`127.0.0.1`だけで待ち受ける。
- Markdown表示時に埋め込みスクリプトを実行しない。
- Markdown内の生HTMLはプレビューへ表示せず、危険なURLスキームをリンクとして有効化しない。画像は外部・ローカルを問わず自動取得しない。
- ログにPDF本文、メモ本文、Box認証情報を残さない。

## 24. ログ

記録対象は次のとおり。

- 起動・終了
- PDF登録の成功・失敗
- ファイル保存の失敗
- SQLite再構築
- バックアップ
- アプリケーションエラー

記録しないものは次のとおり。

- PDF本文
- メモ本文
- Box認証情報
- ユーザーの検索語

ログは30日を超えたものから自動削除する。

## 25. 操作性

- 主要操作をマウスだけで実行できる。
- メインテーマカラーは紺とし、成功・警告・エラーなど意味を持つ色は区別を維持する。
- ライトモードとダークモードを画面上で切り替えられる。
- 選択した表示テーマは次回起動時も保持し、未選択時はOSまたはブラウザの配色設定に従う。
- `Ctrl+S`で書誌情報とメモを保存できる。
- `Ctrl+F`でホームの検索欄へ移動できる。
- 未保存状態を画面上に表示する。
- 長時間処理は1つの全体進捗表示にまとめる。
- 失敗時は原因と対処方法を表示する。
- 危険な操作には確認画面を表示する。
- Windowsの表示倍率125～200%でレイアウトが崩れない。

## 26. 初版の完成条件

### 26.1 初期設定

- Box Drive配下の保存先を選択できる。
- 保存先の存在と書き込み可否を確認できる。
- 必要なフォルダを作成できる。

### 26.2 論文登録・管理

- PDF必須で論文を登録できる。
- PDFがBox Drive上の指定フォルダへ正しくコピーされる。
- タイトルを入力できる。
- 完全に同一のPDFを検出できる。
- 登録直後の状態が「未読」になる。
- 書誌情報を編集できる。
- PDFをWindowsの既定アプリで開ける。

### 26.3 ホーム

- 論文を表形式で一覧表示できる。
- タイトル、著者、キーワードだけを対象に検索できる。
- 状態、発行年、ジャーナル、キーワード、評価で絞り込める。
- 行全体から論文詳細へ移動でき、論文詳細で状態を変更できる。

### 26.4 メモ

- 確定した9項目のMarkdownメモを編集・保存できる。
- 空欄を含むメモを保存できる。
- Markdown記法の色分け、箇条書き継続、Tabインデント、検索、元に戻す、やり直し、太字／斜体／リンクのキーボード操作を利用できる。
- 保存前のMarkdownメモをプレビューできる。
- 未保存のまま画面を閉じる際に警告できる。
- テンプレートを変更できる。
- テンプレート変更によって既存メモが自動変更されない。

### 26.5 キーワード

- 作成、付与、削除、名称変更、統合ができる。
- キーワードで論文を絞り込める。
- キーワードに色を設定できる。

### 26.6 引用関係

- 登録済み論文間に引用関係を設定できる。
- 引用元と引用先を確認できる。
- 重複引用を登録できない。

### 26.7 グラフ

- キーワードグラフを表示できる。
- 引用グラフを表示できる。
- 全体グラフで条件に一致するノードを省略せず表示できる。
- 選択論文のローカルグラフを深さ1～3で表示できる。
- ノードから論文詳細へ移動できる。
- 状態、発行年、キーワードで絞り込める。

### 26.8 安全性

- ごみ箱への移動と復元ができる。
- SQLiteをBox Drive上の正本から再構築できる。
- 軽量バックアップを作成・復元できる。
- CSV、JSON、Markdownへ出力できる。
- Box Driveが利用できないときに別の場所へ勝手に保存しない。
